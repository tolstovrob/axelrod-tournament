# Турнир по итеративной дилемме заключенного на Go.

Проект позволяет проводить турниры между различными стратегиями в повторяющейся дилемме заключенного. Каждая стратегия принимает решения на основе истории ходов соперника. Результаты сортируются по общему количеству очков и могут быть экспортированы в CSV.

## Задача

Два игрока могут либо сотрудничать, либо предавать друг друга. Предательство дает максимальную выгоду в одном раунде, но в долгосрочной перспективе взаимное сотрудничество выгоднее для обоих. Задача стратегии &mdash; найти баланс между этими интересами в повторяющихся взаимодействиях.

Проще говоря, проанализировать поведение стратегий в решении дилеммы заключенного с тенью будущего.

## Создание своей стратегии

Для создания новой стратегии реализуйте интерфейс Strategy:

```go
type MyStrategy interface {
	Name() string
	Move(opponentHistory History) Action
	Reset()
}
```

В вашем распоряжении лишь история ходов соперника.

Если стратегия использует какое-то внутреннее состояние, то не забудьте очистить его в методе `Reset()`.

Если же стратегии нужны параметры запуска, то сделайте их публичными полями структуры и инициализируйте при добавлении стратегии в менеджер.

## Пример использования

```go
config := internal.GameConfig{
    Rounds:       200,
    PayoffMatrix: internal.DefaultPayoffMatrix(),
}

tm := internal.NewTournamentManager(config)
tm.AddStrategy(strategies.TitForTat{})
tm.AddStrategy(&strategies.Kamikaze{BetrayalStart: 120})
tm.AddStrategy(strategies.MyStrategy{})

tm.RunTournament()
tm.PrintResults()
err := tm.ExportResultsToCSV("results.csv")
```
